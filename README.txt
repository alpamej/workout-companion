WORKOUT COMPANION V10

Sequential workout flow:
1. Only the first unfinished set can be started.
2. While a set timer is active, every other set is locked.
3. The next set unlocks only after the current set is finished.
4. The next exercise remains locked until every set in the current exercise is finished.
5. Future exercises and sets cannot be skipped by tapping their timer or checkbox.
6. Completed sets show their exact elapsed time.
7. Exercise headers show current total time and the previous completed total.
